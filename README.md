# ImmortalVoyageGame

《不朽之旅》網頁文字 RPG 的全新重寫版本。

目前狀態：V2 clean rewrite 已啟動。舊版程式已從現行 `main` 工作樹移除；新版將依 Google Drive Game Domain SSOT，從最小可玩生存閉環重新建立。

## 第一階段

出生 → 看見世界 → 移動 → 取得水與食物 → 背包 → 消耗 → 取得與花費貨幣 → 繼續生存

## 原則

- World Engine 是唯一世界真相與最終裁決者。
- AI 只負責敘事與選項，不直接改寫共享世界。
- Game Core 保持小而穩；玩法採 Module／Content Pack 擴充。
- 手機完整可玩，PC 提供更完整的視覺與資訊配置。
